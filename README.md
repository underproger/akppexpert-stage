# AKPP-Expert — стейдж редизайна 2026

Полная копия сайта (MODX 2.6.5 + Babel RU/UA), настроенная под стейдж: https://akppexpert-stage.akpp-expert.com.ua (UA — `/ua/`).

## Развёртывание

1. Залить файлы репозитория в корень стейджа (вместе с `.htaccess`).
2. Положить `core/config/config.inc.php` (в репозиторий не входит — там доступы к БД).
3. Импортировать дамп базы (в репозиторий не входит, передаётся отдельно).
4. `core/cache/` должна быть доступна на запись.
5. PHP 7.x — MODX 2.6.5 на PHP 8 не работает.

В `.htaccess` есть заголовок `X-Robots-Tag: noindex, nofollow`, который срабатывает только для хоста `akppexpert-stage.*` — на боевом домене ничего не меняет.

## Что сделано

**Шапка, мега-меню, мобильное меню, футер** — общие для всех страниц (чанки `header`, `footer`, `head`, `script`).
Меню строится сниппетом `axMenu` из дерева ресурсов (published, hidemenu = 0). Иконки пунктов — TV `menu_icon` (шаблоны 1, 3, 4, 8, 9, 12).

**Главная** (шаблон «Главная», id 1) собрана из чанков `ax.home.*`:
баннер → услуги → о нас → марки авто → о сервисе (видео на повторе) → наш подход → цены → тёмный CTA → галерея → 3 текстовых блока → отзывы → FAQ → SEO-текст → контакты + форма + карта.

Тексты главной редактируются в админке. Заголовки и тексты, которые были на сайте раньше, не менялись и выводятся из прежних полей:
H1 и подзаголовок баннера, «Наши услуги», «Опыт. Профессионализм. Гарантия качества» + текст (`title-main-bl2`, `text-2-bl2`), «О центре ремонта коробок AKPP-Expert» (`title_bl2_about`), «Как выглядит наш сервис», «Цены на ремонт автоматической КПП», «Отзывы наших клиентов», «Контакты», 3 блока «текст-картинка», FAQ, контент страницы.
В H1 часть заключена в `<span>` — она выводится красным с новой строки.

Новые поля — во вкладках «Главная 2026 · …» (строка над H1, карточки с цифрами, преимущества, карточки услуг — ID страницы + иконка, слайдер фото сотрудников и ссылка кнопки «Подробнее о нас» (блок «О нас»), карточки «О нас», марки, постер видео и преимущества блока «О сервисе», «Наш подход», текст рядом с прайсом, тёмный блок-призыв).

Прайс на главной, как и раньше, — таблица в поле «Блок 4 - Цены → Таблица» (`table-bl4`). Сниппет `axPriceTable` разбирает её в строки карточки: заголовок таблицы → шапка карточки, цена в `<span>` → красная плашка, текст после таблицы → примечание.

Тема: `assets/templates/ax/` (`css/ax.css`, `js/ax.js`, шрифты Sofia Sans Extra Condensed, Roboto Condensed, Rubik и Roboto локально, SVG-логотип). Картинки, иконки и логотипы марок: `images/design/ax/`.

Внутренние страницы пока на старых стилях — новые у них только шапка и футер.

Создана страница «О нас» (RU id 261 `/o-nas/`, UA id 262 `/ua/o-nas/`, шаблон «Внутренняя», скрыта из меню, связаны через Babel) — на неё ведёт кнопка «Подробнее о нас». Контент страницы пустой.

На главной подключается `assets/templates/ax/css/fancybox.css` (галерея/видео в модалке): старый `template.css`, где были эти стили, на главной не грузится.
