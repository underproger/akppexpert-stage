# AKPP-Expert — стейдж редизайна 2026

Полная копия сайта (MODX 2.6.5 + Babel RU/UA), настроенная под стейдж: https://akppexpert-stage.akpp-expert.com.ua (UA — `/ua/`).

## Развёртывание

1. Залить файлы репозитория в корень стейджа (вместе с `.htaccess`).
2. Положить `core/config/config.inc.php` (в репозиторий не входит — там доступы к БД).
3. Импортировать дамп базы (в репозиторий не входит, передаётся отдельно).
4. `core/cache/` должна быть доступна на запись.
5. PHP 7.x — MODX 2.6.5 на PHP 8 не работает.

В `.htaccess` есть заголовок `X-Robots-Tag: noindex, nofollow`, который срабатывает только для хоста `akppexpert-stage.*` — на боевом домене ничего не меняет.

## Что сделано

**Шапка, мега-меню, мобильное меню, футер** — общие для всех страниц (чанки `header`, `footer`, `head`, `script`).
Меню строится сниппетом `axMenu` из дерева ресурсов (published, hidemenu = 0). Иконки пунктов — TV `menu_icon` (шаблоны 1, 3, 4, 8, 9, 12).

**Главная** (шаблон «Главная», id 1) собрана из чанков `ax.home.*`:
баннер → услуги → о нас → марки авто → о сервисе (видео на повторе) → наш подход → цены → тёмный CTA → галерея → 3 текстовых блока → отзывы → SEO-текст → FAQ → контакты + форма + карта.

Тексты главной редактируются в админке. Заголовки и тексты, которые были на сайте раньше, не менялись и выводятся из прежних полей:
H1 и подзаголовок баннера, «Наши услуги», «Опыт. Профессионализм. Гарантия качества» + текст (`title-main-bl2`, `text-2-bl2`), «О центре ремонта коробок AKPP-Expert» (`title_bl2_about`), «Как выглядит наш сервис», «Цены на ремонт автоматической КПП», «Отзывы наших клиентов», «Контакты», 3 блока «текст-картинка», FAQ, контент страницы.
В H1 часть заключена в `<span>` — она выводится красным с новой строки.

Новые поля — во вкладках «Главная 2026 · …» (строка над H1, карточки с цифрами, преимущества, карточки услуг — ID страницы + иконка, фото, слайдер сотрудников под блоком на всю ширину (фото + имя + должность) и ссылка кнопки «Подробнее о нас» (блок «О нас»; сейчас поле пустое — кнопки нет), карточки «О нас», марки, постер видео и преимущества блока «О сервисе», «Наш подход», текст рядом с прайсом, тёмный блок-призыв).

Прайс на главной, как и раньше, — таблица в поле «Блок 4 - Цены → Таблица» (`table-bl4`). Сниппет `axPriceTable` разбирает её в строки карточки: заголовок таблицы → шапка карточки, цена в `<span>` → красная плашка, текст после таблицы → примечание.

Тема: `assets/templates/ax/` (`css/ax.css`, `js/ax.js`, шрифты Sofia Sans Extra Condensed, Roboto Condensed, Rubik и Roboto локально, SVG-логотип). Картинки, иконки и логотипы марок: `images/design/ax/`.

**Страницы услуг** (шаблоны «Категория» id 8 и «Подкатегория» id 12 — все услуги, ремонт по маркам, города и разделы «Услуги ремонта» / «Другие услуги» / «По городам») собраны в том же стиле:
баннер услуги → (на разделах — карточки вложенных страниц) → видео + текст об услуге → цены → наш подход → о нас + команда → тёмный блок-призыв → фото «Как выглядит наш сервис» → отзывы → SEO-текст → FAQ → контакты + форма + карта.
- Баннер: заголовок `title-banner`, подзаголовок `sub-itle-banner`, список преимуществ из `description-banner` (каждый абзац — пункт, сниппет `axLines`), картинка `img_banner_main` (если пусто — фото цеха), цифры и преимущества — с главной.
- Цены: таблица `table-bl4` как раньше; текст после таблицы — слева, сноски со «*» — в карточке (`axPriceTable` → `text` / `notes`).
- «Наш подход», «О нас» с командой, тёмный блок-призыв и преимущества блока с видео берутся с главной (правятся там же).
- Отзывы: свои отзывы страницы; если их ещё нет — отзывы о сервисе с главной. Форма отзыва всегда пишет в ветку текущей страницы.
- Галерея (ms2Gallery страницы) без фото не выводится.
- Хлебные крошки теперь одинаковые для RU и UA: Главная → раздел → услуга.

**Контакты** (шаблон «Контакты», id 9; RU 3 / UA 193): те же блоки, что были, в новом стиле — заголовок с крошками → контакты + форма → карта.

**Цены** (RU 44 / UA 182, новый шаблон «Цены (2026)» — раньше были на «Внутренней», которую использует и «Портфолио»): только существующий контент в новом стиле — заголовок с крошками → текст до таблицы + таблица цен карточкой (сноски «*» — в карточке) → остальной текст контента.

Остальные внутренние страницы пока на старых стилях — новые у них только шапка и футер.

**Страница «О нас»** (RU id 261 `/o-nas/`, UA id 262 `/ua/o-nas/`, связаны через Babel). Пока открывается только из админки: скрыта из меню, исключена из карты сайта (галочка «Исключить из карты сайта»), кнопки «Подробнее о нас» на главной нет.
Чтобы открыть страницу: на главной (RU и UA) в поле «Кнопка „Подробнее о нас“: ID страницы» указать 261 / 262, у самих страниц снять «Исключить из карты сайта» (и при желании «Не показывать в меню»).
Отдельный шаблон «О нас (2026)» из чанков `ax.about.*`: баннер с фото → бегущая строка → о сервисе → цифры → 11 этапов ремонта (тёмный блок, номер этапа слева меняется при прокрутке) → принцип (цитата проявляется по словам) → 4 правила → фото цеха → 6 причин.
Все тексты — поля во вкладке «О нас 2026» (TV `ab_*`). Стили — `assets/templates/ax/css/ax-about.css` (грузится только на этой странице), шрифты Inter Tight и JetBrains Mono локально, фото — `images/design/ax/about/`.

На главной подключается `assets/templates/ax/css/fancybox.css` (галерея/видео в модалке): старый `template.css`, где были эти стили, на главной не грузится.
